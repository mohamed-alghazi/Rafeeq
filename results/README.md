# نتائج تجربة الذكاء الاصطناعي

ما فيه نتائج للحين؛ مفتاح OpenRouter ما كان موجودًا وقت الاختبار. اختبارات البرنامج العشرين الناجحة ما تقيس جودة إجابات الذكاء الاصطناعي.

بعد إضافة المفتاح، شغّل:

```bash
uv run --frozen python -m rafeeq.evaluate tasks.jsonl --config A B --trials 1
```

الأمر يحفظ `eval-A.csv` و`eval-B.csv` و`summary.json` هنا. راجع الإجابات والأخطاء قبل إضافة النتائج إلى README الرئيسي.
