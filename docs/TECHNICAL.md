# تشغيل رفيق والتفاصيل التقنية

[الرجوع لشرح المشروع](../README.md)

## التشغيل على جهازك

تحتاج Python 3.11 أو أحدث و[uv](https://docs.astral.sh/uv/). من مجلد المشروع:

```bash
uv sync --frozen
cp .env.example .env
```

إذا عندك ملف `.env`، عدّله بدل ما تستبدله. حط مفتاح OpenRouter مقابل `OPENROUTER_API_KEY`، وكلمة مرور عشوائية طويلة مقابل `RAFEEQ_ACCESS_TOKEN`. لا ترفع الملف إلى GitHub.

```bash
uv run --frozen uvicorn rafeeq.api:app --host 127.0.0.1 --port 8000
```

افتح صفحة الخدمة المحلية في متصفح جهازك، وأدخل رمز `RAFEEQ_ACCESS_TOKEN`. مفتاح OpenRouter يبقى في إعدادات التشغيل، وما ينحط في الصفحة.

النموذج الافتراضي هو `google/gemma-4-31b-it:free` المستخدم في مختبرات الدورة. تقدر تغيّره عبر `RAFEEQ_MODEL` إلى نموذج يدعم استدعاء الأدوات إذا تغيّر توفره.

## البيئة السحابية الحالية

```bash
cd /workspace/Rafeeq
bash scripts/setup.sh
export UV_CACHE_DIR=/workspace/.uv-cache
uv run --frozen uvicorn rafeeq.api:app --host 127.0.0.1 --port 8000
```

السكربت يثبت المكتبات وينشئ رمز دخول في `.env` إذا الملف غير موجود. أضف `OPENROUTER_API_KEY` من إعدادات الأسرار. تعليمات التثبيت والتشغيل محفوظة في مسودة إعدادات البيئة؛ الحفظ لا يشغّل الخدمة أو ينشر البيئة تلقائيًا.

في `/health`، تأكد من `status=ok` و`provider_configured=true` و`access_configured=true`. وجود المفتاح ما يثبت صلاحيته؛ جرّب سؤال الرسوم فعليًا بعد إضافته. طلبات الخدمة المحمية تحتاج `Authorization: Bearer <local-access-token>`.

## الأدوات والحدود

| الأداة | عملها | عبر MCP؟ |
|---|---|---|
| `search_policy` | البحث في ملفات السياسات مع المصدر | نعم |
| `calculate_fee` | حساب الرسوم والتقريب والحد الأدنى | نعم |
| `get_application` | قراءة حالة طلب يخص المستخدم | لا |
| `propose_inspection` | تجهيز موعد ينتظر الموافقة | لا |

| الجزء | القرار |
|---|---|
| Prompt | التعليمات في `rafeeq/spec.md`: لغة الرد، المصادر، والصلاحيات. |
| Context | بحث بالكلمات في ثلاث وثائق. حد 24 ألف حرف للسياق و5 آلاف لنتيجة الأداة. فيه دالة تقلّص سجل العميل إلى 8 آلاف حرف؛ صفحة الويب الحالية لا ترسل سجل الأسئلة السابقة. |
| Harness | 8 طلبات للنموذج، و12 استدعاء أداة، و800 وحدة نصية للإجابة في كل طلب. |
| التكلفة | تقدير 0.006 دولار لكل طلب بسقف 0.05 دولار للتشغيل. ما يمثل فاتورة المزود؛ اضبط حد الإنفاق في OpenRouter أيضًا. |
| Loop | يطلب أداة، ويقرأ نتيجتها، ثم يكمل حتى يجيب أو يصل للحد. |
| Graph والموافقة | حالة الاقتراح pending → approved/rejected محفوظة في SQLite. التنفيذ يحتاج موافقة مستقلة عن النموذج. |

تفاصيل الاقتراح محفوظة ولا يعيد المستخدم إرسال تاريخ بديل مع الموافقة. عند التنفيذ يُفحص صاحب الطلب والتاريخ، وتمنع قاعدة البيانات تنفيذ الموافقة نفسها مرتين.

## اختبارات البرنامج بدون مفتاح

```bash
uv run --frozen pytest -q
```

النتيجة المسجلة: **20 passed**. تشمل الحسابات، والملكية، والموافقات، وربط MCP الفعلي، والحدود، وطلبات الخدمة. في البيئة الحالية احتجنا تشغيلًا يسمح بالعمليات الفرعية لاختبارات MCP.

لمراجعة اختبارات الأمان وحدها:

```bash
uv run --frozen pytest -q tests/test_system.py::test_unavailable_tools_and_cross_owner tests/test_system.py::test_approval_ownership_and_replay tests/test_system.py::test_api_auth_and_approval
```

ثلاثة اختبارات تتحقق من رفض قراءة طلب شخص آخر والأدوات الممنوعة، ومنع الحجز قبل الموافقة وتكرارها، وحماية طلبات الخدمة. هذي اختبارات للبرنامج بمدخلات مبرمجة، وليست تقييمًا لإجابات نموذج حي.

## تقييم إجابات الذكاء الاصطناعي

`tasks.jsonl` فيه 18 مهمة: 10 رسوم، ومهمتان بحث، ومهمة استعلام عن طلب، و3 أمان، ومهمة موافقة، ومهمة استيضاح. **A** التعليمات الأساسية، و**B** نفس الإعدادات مع تذكير بالرجوع إلى السياسة أولًا في أسئلة الرسوم والسياسات.

بعد إضافة المفتاح:

```bash
uv run --frozen python -m rafeeq.evaluate tasks.jsonl --config A B --trials 1
```

يكتب `results/eval-A.csv` و`results/eval-B.csv` و`results/summary.json`. للفحص المتكرر استخدم `--trials 3` وانتبه للحصة والتكلفة. `all_trials_pass_fraction` هي نسبة المهام اللي نجحت في كل التكرارات؛ تجربة واحدة ما تكفي للحكم على الثبات. الأمر يرجع حالة فشل إذا فشلت مهمة.

المصححات تفحص الإجابة المتوقعة والأدوات المستخدمة، لكن وجود كلمة صحيحة وحده ما يثبت صحة الرد. راجع الردود وصنّف الأخطاء إلى فهم السؤال، واختيار الأداة، والوصول للمعلومة، أو مشاكل المزود. بعدين قارن A وB من النتائج. التقييم الحي لم يُشغّل وقت إعداد المشروع لغياب المفتاح؛ ما عندنا للحين نسب نجاح أو تحسّن للنموذج.

## حدود النسخة

البيانات وهمية، والمستخدم واحد للتجربة. المواعيد تواريخ يومية، بدون سعة مواعيد أو عطل رسمية. الحجز محلي وما فيه ربط بجهة فعلية. قبل استخدام بيانات حقيقية، نحتاج حسابات منفصلة وحماية إضافية للبيانات المخزنة ومراجعة ما يُرسل إلى OpenRouter وفق متطلبات حماية البيانات الشخصية. سجل القرارات يحفظ الموافقات بدون المفاتيح أو نصوص المحادثات.
