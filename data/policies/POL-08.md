# POL-08 — Synthetic applicant verification

Before disclosing any application details or preparing an action, verify the last four national-ID digits and registered mobile number. In this project, verification happens only through a dedicated form/endpoint; identity credentials are never model tools or chat context.

An application number alone does not establish ownership. Failed verification returns no record details. Three failed attempts lock the session. Verification expires after 30 minutes. There is no authority to access another applicant's records, approve permits or send personal data elsewhere.

Stored history and traces mask mobile numbers, identity numbers, email addresses, IBANs and credentials. Public policy questions do not require applicant verification.

This is a synthetic course demo, not a production identity system. Source: SDAIA Academy Madar POL-08; session lockout and expiry are project controls.
